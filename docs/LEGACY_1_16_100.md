# Datos históricos de Minecraft Bedrock 1.16.100

`legacy/1.16.100` contiene una instantánea separada del protocolo 419.
La distribución actual conserva intactos sus archivos principales. La presencia
de esta carpeta no anuncia ni activa soporte jugable para clientes antiguos.

Todos los archivos se tomaron sin modificar de
[`pmmp/BedrockData@14f4a765eba40b2c65c6dcd061cbfea6e1d3d4cc`](https://github.com/pmmp/BedrockData/tree/14f4a765eba40b2c65c6dcd061cbfea6e1d3d4cc),
la revisión titulada `Updated from 1.16.100`. Se conserva su licencia original.
El manifiesto registra tamaño, SHA-256 y el identificador Git original de cada
archivo. Las coincidencias con el ZIP de referencia se verificaron por contenido;
los datos de biomas y entidades se obtuvieron directamente de la revisión histórica,
porque los del ZIP no coincidían con ella.

`python3 tools/validate-legacy-data.py` comprueba los archivos, sus hashes y el
diccionario de 914 ítems con identificadores únicos. La validación comprueba también
recetas no vacías e ítems característicos, incluido el escudo con runtime ID 355.

Las recetas son una referencia histórica: sus índices deben reconciliarse con el
gestor de recetas del servidor. No deben enviarse directamente ni sustituir las
recetas registradas por plugins. Faltan la adaptación de metadatos de bloques,
los conversores y la selección por protocolo dentro del servidor.
